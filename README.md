# Nib Tena

Nib Tena is a modern web application designed to streamline healthcare management for hospitals, doctors, and patients. Built with Next.js, TypeScript, and Prisma, it provides secure authentication, role-based access, appointment scheduling, and robust admin features.

## Features
- Secure authentication and authorization
- Role-based access for doctors, hospital admins, and super admins
- Appointment management and scheduling
- User-friendly portals for doctors, admins, and patients
- File upload and image management
- Audit logging and security best practices

## Tech Stack
- Next.js (React)
- TypeScript
- Prisma ORM
- Tailwind CSS
- PostgreSQL (or compatible database)

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Set up your environment variables
4. Run database migrations: `npx prisma migrate dev`
5. Start the development server: `npm run dev`

## Folder Structure
- `src/` - Main application code
- `prisma/` - Database schema and seed scripts
- `public/` - Static assets
- `docs/` - Project documentation
